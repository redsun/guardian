# Repository language

Keep repository-owned filenames, documentation, code comments, user-facing text, and commit messages in English.

Store Chinese translations and planning notes outside this repository, in the sibling `../guardian-notes/` directory. Do not add those files to this repository.

# Documentation audience

Keep repository documentation focused on the project, usage, architecture, deployment, limitations, and reproducible verification. Store internal discussion, presentation scripts, recording schedules, submission preparation, and session-specific work logs in `../guardian-notes/`, regardless of language. English internal notes do not belong in the public README or documentation.
